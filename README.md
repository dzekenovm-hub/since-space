# SINCE SPACE

Интерактивный научно-образовательный сайт на русском языке. В текущей версии используются обычные HTML, CSS и JavaScript — сборка и установка пакетов не нужны.

## Запуск

1. Установи Node.js 20 или новее.
2. В PowerShell из папки проекта задай собственный пароль владельца и запусти встроенный сервер:

   ```powershell
   $env:SS_ADMIN_PASSWORD = Read-Host "Задай пароль владельца"
   node serve.mjs
   ```

3. Открой <http://localhost:5173>. Чтобы выбрать другой порт, задай переменную окружения `PORT` перед запуском.

Кнопка «Вход автора» открывает закрытую панель. Пароль проверяет сервер, а браузер получает `HttpOnly` cookie сеанса. Если `SS_ADMIN_PASSWORD` не задан, доступ закрыт. Для быстрой проверки запусти `./start-local.ps1`: он спросит секретный пароль, выберет порт 5174 и не сохранит пароль в проекте.

Не открывай `index.html` двойным щелчком: без Node-сервера API регистрации, вход, прогресс и закрытая панель не работают. Открой адрес, который напечатан терминалом (`http://localhost:5173` или `http://localhost:5174`). Проверка сервера: `http://localhost:5174/api/health`; ответ содержит `ok: true` и `adminConfigured: true` после безопасного ввода пароля.

Регистрация принимает Username из 3–24 латинских букв, цифр или `_`, имя от 1 до 60 символов и пароль от 10 символов. Если сайт сообщает `404` или `Not found` на `/api/auth/register`, это старый статический сервер: останови его в прежнем окне терминала сочетанием `Ctrl+C`, затем запусти актуальный `./start-local.ps1` и зайди на `http://localhost:5174`.

## Возможности

- Обзор и адаптивная навигация по научным разделам.
- Интерактивная периодическая таблица всех 118 элементов, фильтры, статусы коллекции и Element Quest с серверной проверкой ответов.
- Аккаунты с username, именем, уникальной регистрацией, серверными 30-дневными сессиями и хешированием паролей через Node.js scrypt. Хеш токена сессии хранится в базе, поэтому прогресс Element Quest не зависит от перезапуска процесса. Публичные профили, список участников и рейтинг не раскрывают пароль или его хеш.
- Серверный игровой прогресс: изучение элементов, XP, уровни, стандартные и пользовательские миссии, награды за задания с защитой от повтора, Daily Challenge и публичный рейтинг.
- Личный инвентарь соединений связан с аккаунтом и синхронизируется с локальным Inventory CHEM LAB при входе. В Molecule Builder доступны только изученные элементы.
- CHEM LAB с четырьмя связанными режимами: Molecule Builder, Inventory, Reaction Lab и Equation Builder. Каталог включает 118 элементов и соединения, необходимые для 50 реакций в категориях горения, газообразования, смены цвета, осадков, свечения, быстрых процессов, кристаллизации, окисления, разложения, кислотно-основных и тепловых процессов.
- Общий парсер формул распознаёт скобки, индексы, гидраты и заряды. Equation Builder показывает баланс атомов, расставляет коэффициенты, сохраняет формулы и объясняет результат.
- CHEM LAB показывает реакционный сосуд в настоящем интерактивном WebGL 3D: мышью/касанием его можно вращать, колесом/жестом приближать. Стекло использует физический материал передачи света и отражения; в колбе отдельно анимируются жидкость, пузырьки, взвесь осадка, пена, свечение и визуальный нагрев в зависимости от карточки реакции. Реакционные эффекты запускаются, ставятся на паузу и повторяются. Это образовательная визуальная симуляция, не молекулярная динамика и не расчёт кинетики.
- Инвентарь, уравнения и проведённые опыты хранятся в IndexedDB браузера; вещества из конструктора и продукты реакции можно использовать в Reaction Lab.
- Капсулы времени с отложенным открытием.
- Общая стена коротких сообщений с ником автора и лайками; сервер хранит записи в `.since-space-data.json`.
- Миссии, включая угадывание пароля по буквенным подсказкам, очки опыта и сохранение прогресса.
- Локальная панель автора: управление публикациями, экспорт пользовательских данных в JSON и сброс данных.

## Хранение и публикация

Для публичной версии используется **Cloudflare Workers + D1**. D1 хранит аккаунты, хеши паролей, сессии, Element Quest, инвентарь, стену и данные админки — они не исчезнут после перезапуска. Файлы интерфейса находятся в `public/`, Worker и API — в `cloudflare/worker.js`.

### Публикация в интернете

Нужны Node.js 20+ и аккаунт Cloudflare. Банковская карта для бесплатного плана не требуется.

```powershell
npm install
npx wrangler login
npx wrangler d1 create since-space-db
```

Скопируй `database_id`, который вернёт последняя команда, в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`. Затем выполни:

```powershell
npx wrangler d1 execute since-space-db --remote --file=cloudflare/schema.sql
npx wrangler secret put ADMIN_PASSWORD
npx wrangler deploy
```

Когда `wrangler secret put ADMIN_PASSWORD` попросит значение, введи длинный уникальный пароль автора. Он не попадёт в GitHub, исходный код или браузер. После `deploy` команда покажет публичный адрес `*.workers.dev`. Проверь на нём регистрацию, повторный вход и «Вход автора».

Cloudflare D1 и Worker API описаны в [официальной документации D1](https://developers.cloudflare.com/d1/) и [документации статических файлов Workers](https://developers.cloudflare.com/workers/static-assets/binding/).

## Проверка

```powershell
node --test tests/*.test.cjs
```

Тесты проверяют разбор и балансировку формул, минимальные коэффициенты, соответствие баланса всех 50 карточек, профили визуализации, источники карточек, подбор реакции, регистрацию, сохранность хеша/приватности, серверное прохождение Element Quest и блокировку закрытых элементов в аккаунтном инвентаре.

## Структура

- `index.html` — каркас приложения.
- `styles.css` — дизайн-система и адаптивные стили.
- `app.js` — компоненты страниц, таблица элементов и интерактивная логика.
- `chemistry-core.js` — система формул, балансировщик и IndexedDB.
- `chem-modes.js` — четыре рабочих режима CHEM LAB и общая логика каталога.
- `chem-workflow.css` — стили лаборатории и мобильной раскладки.
- `reaction-library.js` — проверенная база из 50 карточек с категориями, условиями, источниками и профилями анимации.
- `serve.mjs` — статический сервер сайта, приватная админ-сессия, аккаунты, серверная база прогресса и API.
- `elements.json` — общие для сервера атомные данные всех 118 элементов.
- `user-space.js` — аккаунты, публичные профили, Element Quest и игровой UI.
